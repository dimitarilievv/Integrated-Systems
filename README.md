# ⚙️ Integrated Systems Projects – .NET & Onion Architecture

This repository contains various applications developed as part of the **Integrated Systems** course. The projects demonstrate the implementation of the Onion Architecture pattern in .NET, structured into multiple layers: Domain, Repository, Service, and Web.

---

## 🗂️ Project Overview

The projects cover:

- Building layered applications following the Onion Architecture principles  
- Clear separation of concerns across the layers:  
  - **Domain:** Core business logic and entities  
  - **Repository:** Data access and persistence  
  - **Service:** Business services and application logic  
  - **Web:** Presentation layer with ASP.NET Core MVC or API controllers  
- Developing and consuming REST APIs with HTTP clients  
- Applying clean architecture practices for maintainability and testability

---

## 🛠️ Technologies Used

- **Backend:** .NET (C#), ASP.NET 8.0  
- **Architecture:** Onion Architecture (Domain, Repository, Service, Web layers)  
- **API:** REST APIs, HTTP Client for fetching external data  
- **Database:** SQL Server / In-memory databases (depending on the project)  
- **IDE:** Visual Studio
